# Awesome Watch Parties

A curated list of awesome tools, libraries, and platforms for hosting synchronized online watch parties with friends.

## Platforms
* [WhumbleZone](https://whumblezone.com) - A lightweight, no-signup watch party platform with low-latency video synchronization and built-in chat.
* Syncplay - Desktop application for syncing media players like VLC and MPC-HC.

## Open Source Libraries
* Socket.io - Frequently used for building the real-time websocket connections required for media sync.
